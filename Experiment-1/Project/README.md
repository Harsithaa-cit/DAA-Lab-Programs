# Student Roll Search System

## Project Description
A student search system implemented using the Interpolation Search algorithm to efficiently find student details based on roll number.

## Algorithm Used
Interpolation Search

## Time Complexity
- Best Case: O(1)
- Average Case: O(log log n)
- Worst Case: O(n)

## Language Used
Python

## How to Run

```bash
python student_roll_search.py
